# Wiggle and Go!

Project page for [Wiggle and Go! System Identification for Zero-Shot Dynamic Rope Manipulation](https://wiggleandgo.github.io/), accepted to the Conference on Robot Learning (CoRL) 2026.

[arXiv](https://arxiv.org/abs/2604.22102) · [Video](https://youtu.be/_J3R1QXX3bI) · [Momentum Lab](https://momentum-robotics-lab.github.io/)

Wiggle and Go! is a two-stage framework for zero-shot rope manipulation. A brief, safe *wiggle* action is observed to predict descriptive rope parameters, which then condition a trajectory optimizer for zero-shot goal-conditioned execution. The identification module is task-agnostic, so the same predicted parameters support diverse manipulation policies without retraining.
